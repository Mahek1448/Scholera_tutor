# AI Usage

AI tools were used as development assistants during the development of Scholera.

## Tools Used

### ChatGPT

Used for:

- Debugging React and JavaScript errors
- Understanding error messages
- Explaining code and implementation concepts
- Suggesting UI improvements
- Helping structure React components
- Debugging CSS and Tailwind styling
- Debugging light and dark mode issues
- Reviewing and improving some code

### Antigravity

Used for:

- Generating initial UI ideas
- Exploring page layouts
- Creating initial styling and interaction ideas
- Assisting with implementation of some frontend components

## Where AI Helped

AI helped us work faster while debugging errors, understanding unfamiliar concepts, exploring UI designs, and creating starting points for some components.

It was particularly useful during development of the tutor interface, revision section, dashboard, notes interface, and theme styling.

## Where AI Led Us Wrong

AI-generated code was not always correct or suitable for our existing project structure.

For example, some generated styling caused issues with light and dark mode, particularly with hard-coded colors, hover states, text contrast, and component backgrounds.

Some generated implementations also required modification to match our existing component structure and design.

Therefore, AI-generated code was treated as a starting point and was manually reviewed, tested, and modified.

## Our Approach

AI was used as a development assistant rather than as a replacement for understanding the code.

We reviewed and modified the generated code to fit our project requirements.

We are responsible for the final implementation and are able to explain the code and design decisions in the repository.
